# Todo App

A simple Todo application built with React and Redux Toolkit.

---

## Features

* Add todos
* Delete todos
* Mark todos as completed

---

## Tech Stack

* React
* Redux Toolkit
* TypeScript

---

## Setup

```bash
git clone https://github.com/thekaramveer/todo-app.git
cd todo-app
npm install
npm run dev
```
